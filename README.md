# Cost Calculator (backend)

Calculates the cost to manufacture an item of clothing. Vendor selects materials and tasks required to produce apparel item, then executes CTA to yield final tally. Vendor maintains site content via dashboard panels. Built using Sass, React, Router, TanStack Query, TypeScript, Node.js, Express, and MongoDB.

[corresponding frontend repository](https://github.com/scosut/calculate-cost-frontend)
